# 🛒 Sistema POS Picking

Este repositorio contiene el desarrollo del proyecto **Sistema POS Picking**, realizado por el equipo de trabajo.

El proyecto estará dividido en **dos apartados principales**, con el objetivo de mantener una estructura ordenada y facilitar la visualización tanto del desarrollo de las distintas fases como de la aplicación.

## 📁 Estructura del proyecto

```
/
├── fases/
│   ├── fase-1/
│   ├── fase-2/
│   ├── fase-3/
│   └── ...
│
├── app/
│   └── ...
│
└── README.md
```

### 📋 1. Fases

Toda la documentación y el desarrollo correspondiente a las diferentes etapas del proyecto estará dentro de la carpeta:

```
fases/
```

En esta carpeta se organizará el trabajo correspondiente a cada fase del proyecto, permitiendo visualizar su evolución de manera ordenada.

```
fases/
├── fase-1/
├── fase-2/
├── fase-3/
└── ...
```

Cada fase contendrá los archivos y documentos correspondientes al trabajo realizado durante esa etapa.

### 💻 2. Aplicación

Todo el desarrollo del **Sistema POS Picking** estará dentro de la carpeta:

```
app/
```

Esta sección contendrá el código fuente y los archivos necesarios para el funcionamiento de la aplicación.

## 🎯 Objetivo del proyecto

El proyecto tiene como objetivo desarrollar un **Sistema POS Picking**, orientado a apoyar y facilitar el proceso de preparación y gestión de pedidos mediante una aplicación que permita organizar y controlar las distintas operaciones involucradas en el proceso de picking.

## 📌 Organización

La separación entre `fases/` y `app/` permite diferenciar claramente:

- El desarrollo y documentación de las distintas **fases del proyecto**.
- La **aplicación** desarrollada como resultado del proyecto.

De esta manera, el repositorio mantiene una estructura organizada que permite revisar tanto el proceso de desarrollo como el resultado final del proyecto.
